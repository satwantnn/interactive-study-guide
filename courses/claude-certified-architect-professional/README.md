## How to use the guides

GitHub may display the HTML file as code. To use a guide interactively, download the `.html` file and open it in Chrome, Safari, Firefox, or Edge. Guides are designed for personal review and include activities such as flashcards or quizzes where provided.

A useful study routine: read the simplified explanation, work through the scenario, check your understanding, and then consult the original source for more detail.
