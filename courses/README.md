# Interactive Study Guides

Practical, browser-based study guides that make technical topics easier to understand and apply.

I created these guides as learning companions while studying for technical certifications. They focus on clear explanations, real-world examples, architecture decisions, and hands-on review, rather than memorizing definitions.

## Courses

| Course | Focus | Materials |
| --- | --- | --- |
| **Claude Certified Architect – Professional (CCAR-P)** | AI solution architecture, prompting, integrations, evaluation, safety, and operations | [Browse all 7 chapters](claude-certified-architect-professional/README.md) |

More certification and architecture courses may be added under `courses/` over time.

## What to expect

- Plain-English explanations of technical concepts
- Decision-making guidance and practical architecture examples
- Interactive review activities, flashcards, or quizzes where included in each guide
- Links back to the original learning resources for deeper reading

## How to study

1. Choose a course from the table above.
2. Open its chapter list and select a topic.
3. Download the `.html` file and open it in your web browser. GitHub's file viewer displays HTML source instead of running the guide.
4. Work through the material and use the original references to check anything you want to explore in more depth.

No special application or server is needed for these standalone HTML guides.
